# Sol de Casa

Sistema web del **Caso C · Sol de Casa** (paneles solares para casas): sitio público con calculadora de ahorro, inicio de sesión y registro, portal para las familias con paneles (ahorro, compartir, referidos) y panel del equipo (solicitudes, referidos y el análisis de anuncios de la sesión 1).

El proyecto React está en [`sol-de-casa-web/`](sol-de-casa-web/), con su propio [README](sol-de-casa-web/README.md). El material del caso (PDF, Excel) está en [`sol-de-casa-web/docs/`](sol-de-casa-web/docs/).

```bash
npm run setup   # instala las dependencias de sol-de-casa-web (solo la primera vez)
npm run dev     # levanta la app en http://localhost:5173
npm run test
npm run build
```

Cuentas de demostración (contraseña `solar2026`): `familia@soldecasa.cr` y `andres@soldecasa.cr`.

Caso ficticio con fines educativos.
